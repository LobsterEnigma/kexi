# 个人安排、可选分享与图片导出

左侧新增「个人安排」，用于运动、社团、聚会、娱乐、兼职等。活动属于你的账户，不绑定课表方案；切换课表仍显示同一批个人活动。

## 使用方式

1. 点击「个人安排 → 添加安排」，填写名称、分类、颜色、时间，可补充地点和私人备注。
2. 可选单次或全天。每周重复可选择多个星期和结束日期；重复保持活动时区的当地钟点。每次最长 7 天，重复结束日期最长设置到首次活动两年后。
3. 列表按月、按开始时间排列，每页 20 项。点击某次活动可只修改这一次，或修改这次及后续；修改后续保留过去记录，并重设后续的单次例外。通过「编辑整个系列」可重设全部活动及例外。
4. 可取消/恢复单次活动，或结束这次及后续。列表勾选「包括已取消」可找回取消的单次记录。删除整个安排会删除该系列及其例外。
5. 周/月课表会显示个人活动；顶部「显示内容」可分别选择课程、学业任务、个人安排。活动冲突提示但允许保存，编辑页列出与当前课表课程、学习安排或其他个人活动的重叠。

全天活动出现在日期事项栏，跨午夜活动按日期分段显示。活动较多时，可展开日期格中的其他事项。学期外的活动可在个人列表及月视图查看；没有开学日期时先使用个人列表，补全课表日期后再对照日历。

## 分享由你决定

- 创建分享链接时，「此链接包含个人安排」默认关闭。历史链接升级后也保持关闭。
- 分享记录中每条链接有独立开启/关闭按钮。关闭后，下次访问该链接就不再显示个人安排。
- 开启后，查看者能看到其所浏览的课表周内个人活动的名称、分类、时间和地点，**包括之后新增或修改的活动**。已取消的活动不显示。
- 私人备注始终不进入公开页面或图片；公开页面没有活动编辑链接。访客无法通过修改 URL 自行打开个人活动显示。
- 原有密码、到期时间、撤销及管理员分享管控继续生效。

## 导出图片

在原有「导出图片」窗口勾选「包含当前周 / 月的个人安排」。每次打开导出窗口默认关闭，与分享链接设置相互独立。

开启后，定时活动进入周课表时间格或月历，图片底部附完整活动明细（日期、时间、分类、地点），包括全天与跨午夜分段。长名称换行，不在明细内省略。私人备注、学业任务和学习计划不包含在此导出中。

图片高度随明细增长，主题选择和 PNG 下载仍可使用。内容过多超过图片尺寸上限时会明确提示改为按周导出，不会悄悄丢弃活动。

## 更新已有服务器

先备份网站、数据库与 `.env`，在包含 `artisan` 的网站根目录执行：

```bash
php artisan down
```

上传服务器包并解压覆盖，保留现有 `.env`、数据库、`vendor/` 和 `storage/`，不要删除整个网站目录。然后逐条执行，报错时先处理再继续：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

无需在服务器执行 npm。不要执行 `migrate:fresh`。更新后强制刷新浏览器，检查个人安排、分享默认关闭和图片导出开关。
