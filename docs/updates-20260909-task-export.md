# 学业任务导出

在「学业任务」页面点击「导出任务」。可选择当前课表的全部课程，也可勾选一门、多门课程或未关联课程的独立任务。导出包含全部匹配任务，不受列表分页影响。

## 两种导出方式

- **预览 / 另存 PDF**：生成按课程分组的清单，显示完整名称、任务类型、完成状态、提交期限、考试/活动起止时间和地点。点击预览顶部「打印 / 另存 PDF」，在浏览器打印窗口选择「另存为 PDF」。没有服务器 PDF 组件依赖。
- **CSV 表格**：直接下载，可用 Excel、Numbers 或其他表格软件打开。包含 UTF-8 中文标记；任务、学习计划、项目阶段分别占行，并保留所属任务与课程。用户输入的公式前缀按纯文本处理。

可按全部、待完成、已完成筛选任务。默认包含学习计划和 Project 阶段，子项保留各自完成状态；备注和资料链接默认不包含，可按需勾选。所有时间明确按当前课表时区导出。

导出入口仅本人登录后可用，不生成公开链接，不把文件保存在服务器。空范围会显示提示，不会混入其他课表的课程或任务。本次无新增环境变量、依赖或数据库迁移。

## 更新已有服务器

备份网站、数据库和 `.env`。在包含 `artisan` 的项目根目录执行：

```bash
php artisan down
```

上传服务器包并解压覆盖，保留原 `.env`、数据库、`vendor/` 和 `storage/`，不要删除整个网站目录。然后逐条执行，报错时先处理再继续：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

已装上一版时迁移为无操作；从更早版本升级会补齐之前的迁移。无需运行 npm，不要执行 `migrate:fresh`。更新后强制刷新浏览器。

PHP 8.3、SQLite、Chromium 验证单课、多课、全部、独立任务、状态筛选、子计划与备注开关；24 项任务跨列表分页完整导出。检查实际 CSV 下载、UTF-8、公式前缀处理、匿名访问、其他用户课表及非法课程选择。PDF 实际生成 6 页并校验文本完整性及首尾页排版；桌面和 320px 手机预览/选择页无横向溢出。测试数据仅在本机临时数据库中，生产服务器和其他浏览器需更新后验收。
