# 学业任务列表整理

任务增多时，列表不再一次铺开太多内容。默认只看待完成任务，每页 10 项，可切换 20 或 50 项，并通过底部分页继续查看。总数和当前范围始终明确显示，不限制实际任务总量。

## 排序与筛选

- 默认按任务时间从早到晚排列：有提交截止时使用截止时间；没有截止时使用考试/活动开始时间；再没有则使用开放作答/提交时间。都没有时排在最后。相同时间使用固定顺序，避免翻页重复或漏项。
- 可切换时间从晚到早，或最近创建；时间倒序也会把未定时间放在最后。学习计划和项目阶段保留在所属任务内，不改变父任务排序。
- 搜索名称、课程、类型、安排日期默认折叠。点击「筛选条件」展开，填写后点击「应用筛选」。有生效条件时，折叠区域下方会显示标签和「清除筛选」。
- 翻页、切换任务状态会保留筛选和排序。更改筛选、排序、每页数量回到第一页；末页项目减少后自动回到有效页。
- 统计卡片和任务行收紧间距，保留完整可换行标题与时间信息。导出仍包含全部匹配任务，不受列表分页影响。

## 更新已有服务器

先备份网站、数据库和 `.env`，在包含 `artisan` 的网站根目录执行：

```bash
php artisan down
```

上传服务器包并解压覆盖，保留原 `.env`、数据库、`vendor/` 和 `storage/`。不要删除整个网站目录。然后逐条执行，报错时先处理再继续：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

上一版已安装时迁移没有新增操作；更早版本会补齐之前的迁移。无需运行 npm，不要执行 `migrate:fresh`。更新后强制刷新浏览器。
