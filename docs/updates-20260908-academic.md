# 学业规划与周日期修复版

## 新增功能

- Assignment、Quiz、考试、Project、阅读和其他任务，可关联课程或独立创建。
- 分别记录开放作答/提交窗口、截止时间，以及实际考试/活动时间。
- 一项任务可以添加多次个人学习计划，支持地点、备注、跨午夜和完成状态。
- Project 可添加阶段节点，每个阶段独立截止、提醒和完成，并显示进度。
- 周课表日期栏显示截止/开放事项；学习和考试进入时间格，时间重叠时显示提示。
- 月历显示任务、项目阶段和学习安排；任务可按状态、课程、类型、名称与日期筛选。
- 站内提醒支持到时、提前 15 分钟、1 小时、1 天、3 天或 1 周，可确认已读；任务完成后停止相关提醒。

站内提醒在网站页面打开时每分钟检查，关闭网站后不会发送推送或邮件。本次不新增环境变量、依赖包、队列或定时任务。任务与个人学习安排默认私有，不包含在公开分享或课程图片导出中。

## 日期修复

2026 年 9 月 8 日是周二。旧版把开学日期直接放在周一列，造成非周一开学时的错位。现在统一为「开学日期所在的周一至周日是第 1 周」：例如 9 月 8 日开学，第 1 周显示 9 月 7 日至 13 日，开学前的 9 月 7 日不生成课程。

日期跳转、月历周号、请假日期和导出同步修复。迁移会保留已保存的真实结课日期，重新计算包含首尾部分周的总周数；原本覆盖整个学期的课程范围同步延长到新的最后周。已经存在的星期/日期不匹配的请假记录也会修正，操作时间不改变。此数据修正不会在 `migrate:rollback` 时反向改回错误日期，回退请恢复更新前数据库备份。

## 两个包的用途

- `kexi-academic-planner-20260908.zip`：完整干净源码，用于手动覆盖 GitHub 仓库后提交；不包含 `.env`、数据库、依赖、测试产物或前端构建。
- `kexi-server-academic-planner-20260908.zip`：已有网站的覆盖更新包，包含 `public/build/`，需要保留现有 `vendor/`。

## 更新已有服务器

1. 备份网站、数据库和 `.env`。SQLite 请使用一致性备份，避免只复制正在写入的主数据库文件。
2. 在包含 `artisan` 的项目根目录执行：

```bash
php artisan down
```

3. 上传服务器更新包并解压覆盖到项目根目录。保留原 `.env`、`vendor/`、`storage/` 和数据库；不要先删除整个目录。
4. 逐条执行，任何一步报错时先处理错误，不要继续后续命令：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

本版包含新数据表和日期修正，必须执行 `migrate --force`。不用重建数据库，不要执行 `migrate:fresh`。服务器更新包自带前端构建，不需要运行 npm。

5. 刷新网页，检查 9 月 8 日位于周二，打开「学业任务」创建一条任务验证保存与日历显示。

## 更新 GitHub

把源码包完整解压覆盖到自己的本地 GitHub 仓库，保留仓库的 `.git`；在 GitHub Desktop 查看变更，填写提交说明（例如 `Add academic planner and fix teaching week dates`），Commit 后再 Push。此过程不会更新线上服务器，需要另按上面的服务器步骤操作。

## 验证范围

本地 PHP 8.3 + SQLite 和 Chromium 验证任务/阶段/学习计划的创建、编辑、完成、删除；输入校验、跨用户与跨任务权限、提醒已读与重开、UTC 时间持久化、跨午夜拆分、周一对齐、首尾周边界、历史日期修正、私有分享隔离与桌面/手机布局。MySQL/MariaDB 和生产服务器需在实际环境中验收。
