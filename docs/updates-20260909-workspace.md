# 工作台界面统一与后台表格修复

最新追加：学业任务表单错误提示改为与内容对齐的浅色卡片，区分图标、标题和错误说明，提示下方留出间距。单条错误简洁显示，多条逐项排列，兼容手机换行；验证规则和输入保留行为不变。已通过桌面 1680px、手机 390px/320px 的实际校验错误和输入保留检查。

本次追加界面精简：删除任务页「学业规划」副栏和右侧课表选择框，统一从左侧课表方案切换对应的任务；手机在导航抽屉内切换。任务页标题栏缩为单行，不保留空白副栏。提醒改为铃铛工具按钮，「学期问题」更名「课表检查」，两者统一样式和展开状态；手机只保留一处检查入口。

- 修复后台用户表格未铺满面板、操作列对齐不一致的问题。长姓名、邮箱和处置原因自动换行，手机可在表格内横向滚动。
- 移除课表顶部重复的「学业任务」入口，保留左侧导航；手机通过导航抽屉进入。
- 学业任务列表、新建和编辑页面复用课表侧栏、品牌、学期标题和账户入口。选中状态跟随当前页面，切换课表方案后继续查看该方案的学业任务。
- 任务页的分享管理和新建课表会回到对应课表并打开相应面板。手机支持抽屉关闭、Escape 和键盘焦点循环，内容区域可独立滚动。

本次不新增环境变量、依赖或数据迁移，课程和任务数据结构不变。完整包包含上一版学业规划功能及日期修复。

## 更新服务器

先备份网站、数据库与 `.env`，在包含 `artisan` 的网站根目录执行：

```bash
php artisan down
```

把服务器更新包解压覆盖到网站根目录，不要先删除原目录。随后逐条执行，遇到错误先处理再继续：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

已经安装上一版时迁移为无操作；从更早版本升级时，它会补齐学业任务数据表和教学周日期修正。不要执行 `migrate:fresh`，不要重新生成 `APP_KEY`。服务器包已编译前端，无需运行 npm。更新后强制刷新浏览器。

首次安装请使用 README 中的源码安装流程。更多关于上一版的数据修正规则见 [学业规划更新说明](updates-20260908-academic.md)。
