# 2026-09-05 更新：课程配色与请假记录

## 新功能

- 按“同一课程 + 授课类型”统一配色，例如数学的 Lecture 同色，Tutorial 可独立选色。类型名称忽略首尾空格和英文字母大小写。
- 提供预设色板和自定义颜色，周课表、月课表、分享页与导出图片同步使用。时间冲突仍显示红色提示，取消课程保持淡色删除线。
- 单次或批量取消课程时，可以选择节假日、身体不适、个人请假、教师停课、突发事件或其他原因，并补充备注。
- “请假与停课记录”保留取消、恢复与时间段移除的操作历史，可按课表/学期、课程、原因、操作和课程日期筛选。每条记录保存操作时的课程名称和上课时间。
- 原有停课数据自动导入记录，标记为“历史记录（未填写原因）”。修改课程和颜色不会重新创建已有时间段，也不会清空停课数据。
- 记录仅课表所有者可见，分享页和导出图片不包含取消原因或私人备注。删除课程后保留历史快照；删除整个课表或账户时，关联记录一并删除。

## 已有网站使用覆盖更新包

`kexi-server-update-20260905.zip` 包含完整源码与 `public/build/`，用于已经正常运行的课隙网站。本次 `composer.json` 和 `composer.lock` 与 `kexi-week-dates-20260904.zip` 完全一致，因此保留原有 `vendor/` 即可。此包不包含生产依赖，不适用于空目录首次安装。

1. 备份数据库和 `.env`，在网站根目录执行 `php artisan down`。
2. 将覆盖更新包上传并解压到网站项目根目录（包含 `artisan` 的目录），覆盖同名文件。不要删除原目录、`.env`、`vendor/`、`storage/` 和数据库。
3. 逐条执行下面命令，全部成功后再恢复访问：

```bash
php artisan migrate --force
php artisan optimize:clear
php artisan optimize
php artisan up
```

## 从源码更新服务器

源码 ZIP 用于 GitHub，不包含 `.env`、数据库、`vendor/` 或 `public/build/`。

更新前备份现有 `.env` 和数据库。SQLite 应使用 `.backup` 或 `VACUUM INTO` 创建一致性备份；仅执行维护模式后复制主数据库文件并不足以保证 WAL 数据完整。保留原有 `APP_KEY`，不要重新生成密钥。

在网站项目根目录执行，每步成功后再执行下一步：

```bash
php artisan down
# 此时通过 git pull --ff-only 或上传解压覆盖方式更新源码。
composer install --no-dev --optimize-autoloader
npm ci
npm run build
php artisan migrate --force
php artisan optimize:clear
php artisan optimize
php artisan up
```

本次必须执行 `migrate --force`，用于新增课程配色字段、停课原因字段和历史记录表。不要执行 `migrate:fresh`、`db:wipe` 或覆盖服务器数据库。出现错误时先停止更新并检查日志，不要直接开放半更新的程序。

站点运行目录仍然指向项目的 `public/`。更新后检查一次修改颜色、取消课程、恢复课程和查看记录的操作。
