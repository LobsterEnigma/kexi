# 学业任务底部工具栏

排序、每页数量和翻页统一移动到任务列表底部。工具栏在内容区吸底，长列表滚动时随时可用；手机分为两行，不挤压控件。滚到末尾后，最后一条任务可完整显示在工具栏上方。

顶部只保留状态分类、数量和折叠筛选。排序规则放在排序旁边的问号按钮内，点击查看，再次点击、点击外部或按 Esc 关闭。

原有排序、10/20/50 项分页、参数保留和全量导出规则不变。本次无需新增环境配置、依赖或数据库迁移。

## 更新服务器

备份网站、数据库和 `.env`。在包含 `artisan` 的网站根目录执行：

```bash
php artisan down
```

上传服务器包并解压覆盖，保留现有 `.env`、数据库、`vendor/` 和 `storage/`。不要删除整个网站目录。然后逐条执行，报错时先处理再继续：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

无需运行 npm，不要执行 `migrate:fresh`。更新后强制刷新浏览器。
