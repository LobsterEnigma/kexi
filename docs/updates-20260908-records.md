## 服务器更新

先备份网站和数据库，在包含 `artisan` 的项目根目录执行：

```bash
php artisan down
```

把服务器更新包解压覆盖到该项目根目录，保留原 `.env`、`vendor/`、`storage/` 和数据库，不要先删除网站目录。然后逐条执行：

```bash
php artisan optimize:clear
php artisan optimize
php artisan up
```

如果还未更新过 2026-09-05 的课程配色与请假记录版本，先在 `optimize:clear` 之后、`optimize` 之前执行 `php artisan migrate --force`。最后刷新浏览器页面。

本次验证使用独立本地测试数据库，覆盖桌面与手机的空状态、记录列表、筛选、分页、学期切换和权限隔离；未连接生产服务器。
