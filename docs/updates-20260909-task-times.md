# 学业任务时间说明与显示修复

## 这次更新

- 「开放与截止」改为「提交期限」，说明开始接受作答/提交、最晚提交时间的含义，并给出作业例子。
- 「考试 / 活动时间」改为「考试或活动安排」，说明固定参加时段、开始结束一起填写，并给出课堂 Quiz 例子。
- 两组均可按需填写，不需要全部填写；自己的写作业、复习时间在保存后的「我的学习计划」中安排。
- 开放时间和提交截止时间现在可以分别单独保存，不知道另一项时留空即可；只有两项均填写时才要求截止晚于开放。
- 只有开放时间的任务在开放当天显示「开放 · 截止待定」，不会被当作无限提交窗口铺满之后的日历。
- 列表显示完整的考试/活动起止时间，跨日、跨年保留相应日期。有考试或学习安排时不再显示「未设截止时间」；有提交期限时单独显示「提交截止」。已有数据不需要重填，也不会把考试结束时间自动改成提交截止时间。

没有新增环境变量、依赖或数据库迁移。包中包含之前的全部修复。

## 两个包

- `kexi-task-times-20260909.zip`：干净完整源码，解压覆盖自己的 GitHub 仓库后自行提交、推送；保留 `.git`。
- `kexi-server-task-times-20260909.zip`：服务器覆盖更新包，包含编译好的前端资源。

## 更新已有服务器

先备份网站、数据库和 `.env`。在包含 `artisan` 的项目根目录执行：

```bash
php artisan down
```

上传服务器包并解压覆盖，保留现有 `.env`、数据库、`vendor/` 和 `storage/`，不要先删除整个目录。随后逐条执行，任何一步报错先处理再继续：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

前端已构建，无需运行 npm。已更新到上一版时迁移为无操作；更早版本会补齐之前的学业任务表和教学周日期修复。不要执行 `migrate:fresh`。更新后强制刷新页面。

## 本地验证

PHP 8.3、SQLite、Chromium：说明文字与学习计划跳转、1680/390/320px 布局；只有考试时段、只有截止时间、两者都有、跨日/跨年、未定时间的列表显示；只填开放时间的创建/修改/持久化、补填及移除截止时间、相等/倒序时间拒绝、按日期筛选和周/月日历开放当天标记。测试只使用本机临时数据库，生产服务器未操作。
