# 个人安排表单与显示面板优化

## 本次更新

- 「显示内容」改为有标题、图标、选项说明与底部操作区的小面板；支持点击外部或 Esc 收起，手机不超出视口。
- 活动颜色改为 8 个紧凑色点，使用勾号标明选中，支持自定义颜色和实时活动标记预览。
- 定时活动合并为「开始日期与时间」「结束日期与时间」两个输入；全天活动只填写起止日期，结束日期包含当天。
- 修改开始时间至原结束时间之后时，结束时间按原合理时长顺延；仍可手动调整，支持跨天活动。
- 新建安排自动识别浏览器设备时区，默认时间使用设备当地时间。用户可手动改时区，修改后以所选时区解释输入时间，不自动换算钟点。
- 编辑已有安排、验证失败返回时保留所填时间与时区。检测不可用时使用课表默认时区并提示确认。

无需新增环境变量或安装依赖。本次美化没有新增迁移，但从个人安排功能之前的版本升级时仍需要执行已有迁移。

## 更新包

- `kexi-personal-polish-20260910.zip`：完整干净源码，用于覆盖你的 GitHub 本地副本后自行提交。
- `kexi-server-personal-polish-20260910.zip`：已有服务器覆盖更新包，带 `public/build`，无需在服务器运行 npm。

压缩包包含此前功能与本次改动，不包含 `.env`、数据库、测试文件、`.omx`、`DESIGN.md`、`node_modules` 或 `vendor`。

## 更新已有服务器

先备份网站、数据库和 `.env`，进入包含 `artisan` 的网站目录：

```bash
php artisan down
```

解压服务器更新包覆盖，保留现有 `.env`、数据库、`vendor/` 和 `storage/`，然后逐条执行（有报错先处理）：

```bash
php artisan optimize:clear
php artisan migrate --force
php artisan optimize
php artisan up
```

刷新浏览器后检查新表单。不要执行 `migrate:fresh`，也不要删除整个网站目录。
