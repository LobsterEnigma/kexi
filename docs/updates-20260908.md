```bash
php artisan optimize:clear
php artisan optimize
php artisan up
```

如果尚未安装 2026-09-05 版本，在刷新缓存之前先执行 `php artisan migrate --force`。源码 ZIP 不包含前端构建；服务器更新包包含 `public/build/`，已有网站无需重新运行 npm 构建。
